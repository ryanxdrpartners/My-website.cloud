# my-website.cloud

Static five-page site: `index.html`, `services.html`, `work.html`, `about.html` (Approach) and `contact.html`, sharing `styles.css` and `main.js`. No build step.

- `logo/` holds the standalone logo mark as SVG (static and animated).
- The contact form opens the visitor's email app. To receive submissions directly, connect a form service before deploying.
- Replace the placeholder address `hello@my-website.cloud` with a real inbox.
